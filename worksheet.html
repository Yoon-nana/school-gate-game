2. 말도 안 되는 해결 방법 만들기

BUILD / 게임 제작 프롬프트 생성기

3. 우리 아이디어를 게임 규칙으로 바꿔요

제작 1. 페이즈 확장하기

이제 이렇게 실행하세요
  1. 수업에서 사용하는 코딩 AI를 엽니다.
  2. 이어 만들기라면 선생님이 준 페이즈 1·2 HTML 파일을 먼저 첨부합니다.
  3. 복사한 프롬프트를 붙여 넣고 코드를 요청합니다.
  4. 완성된 HTML을 다운로드해 브라우저에서 엽니다.
  5. 친구와 실행해 보고, 작동하지 않는 장면을 구체적으로 적어 수정 요청합니다.

이 활동지는 요청문을 조합합니다. 실제 게임 코드는 코딩 AI에서 생성합니다. 아이디어를 수정했다면 버튼을 다시 눌러 요청문도 갱신하세요.

확인: 페이즈 2·3의 장애물과 반전이 나오나요? 일반 장애물은 무적 상태로 통과하면서 장면을 확인하세요.

제작 2. 충돌 규칙과 클리어 조건 만들기

1단계 코드를 첨부하고 충돌 규칙과 클리어 조건을 함께 추가하세요.

확인: 충돌하면 시작점으로 돌아가나요? 조건을 지키면 클리어하고, 조건을 지키지 않으면 플레이가 계속되나요?

제작 3. 공익적인 메시지 담기

2단계 코드를 첨부하고 게임에서 발견한 의미를 전달하세요.

확인: 게임에서 한 행동과 메시지가 연결되나요? 근거 없는 통계가 들어가지는 않았나요?

REFLECT
